## Лабораторная работа 4
Был реализован компонент EcoVirtualMemory
Компонент декларириует 2 основных интерфейса Free, Alloc
При аллоцировании памяти используется метод Worst Fit

VirtualMemory - потому что память выделяется "виртуально", без взаимодействия с железом.

Для тестирования были написана тесты с аллоцированием памяти для строки. 
Кроме того, тесты показывают переиспользования памяти и аллоцирование WorstFit
Также показан функционал работы на qemu.
